# Multimodal Malware Detection (MMD)

Multimodal malware **family classification** on the [MOTIF](https://github.com/boozallen/MOTIF) dataset, combining RGB image representations, audio waveform representations, and interpretable static PE features.

The project studies how different modalities capture complementary structural, sequential, and semantic characteristics of malware binaries, and how they can be fused — including via cross-attention and hyperbolic fusion.

## Repository Layout

The repo is organized by version. Each version folder is self-contained (its own README, report, requirements, and scripts).

```
MMD_versions/
├── README.md                 ← this file (project overview)
└── MMD_V1/                   ← v1: baselines, fusion, static, hyperbolic
    ├── README.md             ← what v1 does + key results
    ├── REPORT_V1.md          ← full experiment report
    ├── requirements.txt
    ├── data_preparation/     ← binary → RGB / audio conversion, family setup
    ├── baselines/            ← grid-searched SVM/LR/MLP probes + final eval
    ├── fusion/               ← cross-attention + hyperbolic fusion; vit_vgg_fcn/
    ├── static/               ← BERT-on-static-PE-features models
    ├── utils/                ← ViT training + confusion-matrix plotting
    └── results/              ← family distribution + confusion matrices
```

Future versions will be added as sibling folders (e.g. `MMD_V2/`).

## Dataset

[MOTIF](https://github.com/boozallen/MOTIF) — 3,095 disarmed PE malware samples across 502 families, with family-level ground-truth labels. The dataset is highly imbalanced and is **not** included in this repo; see the v1 README for the expected family-wise directory structure.

## Notes

Large model/embedding artifacts (`*.pt`, `*.pth`, embedding folders, etc.) are excluded via [`.gitignore`](.gitignore) and must be regenerated by running the scripts.
